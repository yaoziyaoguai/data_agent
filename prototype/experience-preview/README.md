# Data Agent 体验优化原型

这是根据 2026-10-10 UI/UX 审计制作的可点击预览，用于评审页面布局和交互。正式 React / Rust / Pi 应用未被替换，所有内容均为从零构造的合成材料。

## 打开

直接打开同目录的 `preview.html`。它包含样式、脚本和文本测量工具，无外部网络依赖。

也可以从项目根目录启动：

```sh
python3 -m http.server 8868 --bind 127.0.0.1 --directory prototype/experience-preview
```

访问 `http://127.0.0.1:8868/`。原型与正式应用的 5173 端口独立。

## 建议体验顺序

1. 工作台：查看收入结果，切换数据与趋势，复制最终 SQL，下载完整 CSV。
2. 查看口径依据：阅读定义和过滤条件，点击“返回对话”。
3. 输入“执行这条”：演示后台查询；执行期间可以继续输入其他问题，并单独停止查询。
4. 语义管理：查看表定义和字段；修改字段后关闭，体验未保存提醒。
5. 业务文档：从目录打开整篇说明，编辑并切换阅读预览。
6. 我的积累：搜索记忆；在“我的 Skill”中创建方法、采用模板；将个人 Skill 明确发布为空间公共区的独立副本。

## 设计取舍

- 延续系统中文字体、菱形品牌标记、灰蓝配色和三个主要入口。
- 工作台先给结论和结果，最终 SQL 与依据继续保留；输入区收紧，模型和思考设置仍在输入框内。
- 表以单一身份呈现，来源在详情中汇总。本原型不对正式目录执行去重。
- 语义页面压缩多层页头，使用紧凑字段行。文档整篇展示，长文提供章节入口。
- 个人记忆与方法采用列表，长原文在详情中阅读。个人与公共归属在创建、选用和发布时说明。
- 编辑弹窗的主体独立滚动，操作栏固定；未保存时关闭或按 Esc 均有保护。
- 侧栏的历史列表独立滚动，账户固定在底部。手机通过抽屉打开导航。
- 主操作有按下反馈，弹窗有短过渡，首屏仅首次淡入；支持减少动效偏好。动效未独立评审。

删除或收起了导航编号、常驻模型标牌、重复字段标题、资产的重复原文和常驻来源同步信息。

## 原型边界

- 查询与回复由本地固定流程演示，不接模型、Datasight、MySQL、Mem0 或向量库，不消耗模型 API 用量。
- 下载是真实生成的合成 CSV，31 行，合计 128,436.50 元；页面预览前 10 行。
- 编辑仅保存在当前页面内存中，刷新后恢复合成材料。地址保留当前页面、对象与标签。
- 角色、权限、版本冲突、真实查询取消回执和保存失败仍需正式应用实现与验收，不能以原型代替这些验证。
- 页面默认浅色，沿用现有系统方向；未扩展暗色主题。
