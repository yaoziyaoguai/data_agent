“以后改成 app。” 修订原资产，提升正式版本 删除旧版本的派生记录，再整理新版本
共同的保存入口会影响两组

本轮发现，引用完整首句也可能被保存校验拒绝。 原方案的记忆因此没有写入。 Mem0 组也会在这一步停止，尚未进入整理。 增加后续检索能力无法补回这条未保存的记忆。
