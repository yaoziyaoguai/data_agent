BM25寻找字面匹配。dense寻找语义相近内容。RRF把两路排名合并，精确身份有优先处理。同类高相关字段可以一起返回。

公共命中包含两种内容。知识条目提供已整理的定义、条件和关系。原文片段直接指向文档或生产SQL的具体修订与位置。

命中回源后，Rust交付相关正文和已知必要条件。Pi根据缺口补读字段结构、例外或相邻段落。检索返回值同时说明内容、支持和覆盖情况。

回执信息 Pi据此判断什么

本人记忆进入用户与空间隔离的资产分支。已选Skill提供目录和版本，正文与附件通过Pi原生read按需读取。

索引滞后或通道不可用时，系统按现有能力使用当前资料读取或词法路径，并在回执中表达覆盖缺口。资料范围在各召回通道及回源交付时生效。

D

SQL异步完成后，解释从这里继续

自动结果输入携带原query、任务和条件版本。Pi按实际SQL和绝对日期解释结果。恢复和结果唤醒沿用原操作与预算身份。

一份结果答案可以引用多个合法查询。答案归属和实际来源分别保存。组合交付时，每份正文保留原来源及适用范围。

数值通过结果单元格、参数或同范围统计绑定。需要额外计算的差值、比例和分组进入相应SQL。新增补算查询按其授权范围处理。

用户要求保存报告时，Pi先保存可引用的分析依据，再组合报告与图表。方法复用请求会生成私人Skill草稿，用户在个人积累中核对和保存。
