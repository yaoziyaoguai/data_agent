## 验证与复测

| 场景 | 观察行为 |
| --- | --- |
| 用户限定域查空 | 每一次`search_knowledge`保留`business_domain`；范围内改写或说明缺口，不先去其他域查完再披露 |
| 用户明确扩大范围 | 仅扩大到获准范围，注明资料所属域；不新增SQL执行权 |
| 名称存在多个计算含义 | 无适用用户约定时持久保存一个澄清问题，不先存默认SQL；回答后沿原任务修订，仍不执行 |
| 金额输出分 / 以元显示两位 | SQL表达式、列名、草稿摘要与主结论单位一致；不擅自永久修改偏好 |
| 粘贴SQL后明确修改并执行 | 原话引用仍是含旧SQL的完整用户消息，执行对象则是修改后的新稿。参数错误不能复用旧调用身份；新调用完整引用后同一查询只提交一次 |
| 同步失败、恢复、发送失败及查询完成 | 临时提示可读可操作，输入框坐标不变；草稿、焦点、查询顺序与回看历史位置保持 |
