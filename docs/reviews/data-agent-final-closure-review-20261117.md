## 最终实现边界

`SourceContextBlocker` 是同源 Schema 中的可选控制字段，取值为 `input_not_routed`、`source_scope_unknown`、`context_refresh_pending`。Rust 复用原有归属、有效来源声明及刷新条件计算它，同时派生原 `source_context_ready`；没有增加数据库状态、授权状态或额外来源校验。

Node 仅把宿主原因、控制身份和固定指导放入模型可见输入，不根据投影后的条件是否含字段推断范围。当前修订省略来源声明仍可能继承旧修订，由 Rust 原查询判断。等待刷新时保留暂停状态；刷新就绪后去掉旧原因，继续原任务及原选 Skill 版本。旧回执或快照可以没有新字段，不据此视为就绪，也不重放创建。

来源未知时，route 不获得隐式修订职责。确无额外限制仍由 Pi 按真实用户原话调用原 revise/unset；有限制则保存原允许集，真实歧义仍登记澄清。选中 Skill 不豁免来源限制，读取成功不授予执行权。没有新增模型复核、循环检测、累计调用帽或答案特判。
