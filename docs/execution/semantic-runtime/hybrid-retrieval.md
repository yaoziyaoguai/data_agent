# 原文与知识的中文混合检索

前置：03提供当前原文、陈述/依赖、两类待办；受限取证接04。需求 D04/D06/D07、C02/C06/C07、A06/A09；职责 M01/M02/M03/M04/M09/M10。保持D10/D11/D12现有个人资产能力。

## 结果与范围

原文无需等待模型整理即可进入索引；同一公共集合中原文与正式知识共同相关性排序，中文否定/顺序/例外仍可检索；权限及明确来源限制在每条召回通道先执行。

允许retrieval模块、knowledge索引队列公开入口、ingestion准备/来源读接口、`knowledge_embeddings.rs`与相关取证用例、Worker、现有索引目标配置、相关测试与文档。真实Milvus3.0.2适配验证属于本包；不另选图数据库、不迁移Mem0、不建设长期双索引。

## 切片与接口

1. 用代表性本地实际REST请求验证当前Milvus的Jieba search、BM25函数/sparse、1024维dense及标量过滤。先小样验证创建/写入/检索/删除目标测试集合，记录版本及请求形状；不凭官方SDK示例称当前REST已支持。仅用专用测试集合，不删除现用公共/个人集合。
2. 索引目标区分source_excerpt与knowledge_entry。raw键绑定SourceKey/revision/locator/切块版本；knowledge键绑定EvidenceRef/statement_id/投影版本。chunk_id只是可重建索引键，不是业务引用。原文正文与结构背景分别记录来源。
3. 同一来源raw确定性切块持续至结束，整理pending/failed也可索引；knowledge成果单独待办。原DDL/ETL全文不再重复当另一份knowledge_entry入索引，但旧条目读取仍兼容。状态与租约代次按输入修订核验，晚到作业不能回退当前投影。新目标仅由认识其kind/schema的消费者领取；消费者尚未就绪时保持真实pending，旧消费者不得误领、标完成或耗尽重试。沿既有队列的目标判别/领取过滤实现，后包按原身份接续，旧作业继续正常推进。
4. `build_index_payload`、`search_candidates`等必要公开接口留在retrieval；允许集由组合层经access/knowledge/ingestion公开查询提供。按ID批量元数据与实际贡献根查证，不跨私表、不装全对象正文建立允许集。
5. 精确名称/标识＋Jieba search BM25＋dense；保留中文原文及“未/首次/最终/除外”等含义词，不用整个对象JSON作索引文本。初值RRF k=60、BM25/dense同权、精确ID优先；无类型配额、无raw/knowledge配额、不新增reranker。
6. 权限/端点/source_limits在每路候选检索前执行。知识记录满足有效required依赖及全部实际贡献来源；raw按owner/来源/范围。大允许集分批时，同通道按可比较原始分数合并、去重、排序，再入RRF；不把局部RRF相加，不先全库top-k后过滤。
7. 每路首批max(50,5×limit)，不足再扩；合计1000候选/5批/10秒是初值。候选先相关性排序，禁止数据库ID take(1000)再评分。通道无法执行范围则标不可用，未查完允许集/到界报告bounded和原因。
8. 元信息每批≤50，选中命中≤30才读定义/片段及必要支持，不读整篇/整表字段。相交raw窗口可有界合并≤2400字符及余量；不能链式合并成全文。同文不同位置保留，同源raw/知识不冒称独立证据。
9. 搜索索引滞后时回源复核：旧offset不能切新原文，无法证实时舍弃并说明index_lag。已知ID仍可正常读当前内容；不退回全库扫描，不监听/提醒旧分析变化。

本包先通过实际索引→候选→owner回源的局部集成证明召回行为；完整v2公开hit/游标由06接入。不篡改v1 `business_domain/related_object_id`硬过滤语义或假装raw已能通过旧形状完整交付。新公共集合在专用环境准备，最终统一切换按08，现有集合不长期双写。

## 必须覆盖

| 数据/故障 | 断言 |
| --- | --- |
| 同表3个高分字段＋其他6类弱命中 | 第一次候选/最终选中保留3字段，后续06验证实际回执 |
| 1200对象，高分对象在存储顺序末尾 | 仍按相关性返回；不能用1000候选限额解释排序前误截断 |
| 整理pending/failed；目标只在第129块后 | raw可召回且回读修订/位置一致，无固定总块数截断 |
| 一文多表、多处相同字词/不同定义 | 文档级关联不扩归属；不同位置不按文档ID全部去重 |
| 否定/首次/最终/除外，完整标识和别名 | 中文分析器保留区分信息；记录实际词项与检索结果 |
| allowed set多批＋不同原始分数 | 同路全局排序再融合；未覆盖如实bounded；无过滤后补丁 |
| 权限/来源限制变化、空贡献根人工条目 | 每路只召回允许record，回源重核；不泄露受限数量/名称 |
| raw/knowledge重复、索引晚到/重建 | 同源关系保留，弱知识不挤高相关raw；不重调语义模型 |
| 通道不可用/未配置/索引滞后 | 真实降级状态，仍可范围内其他通道；不空结果伪成功 |

## 检查与性能证据

扩展 `make verify-hybrid-retrieval`、`make verify-shared-embedding`，以及 `check-retrieval-coverage.mjs`、`check-index-concurrency.mjs`、`check-context-dependencies.mjs` 和Rust retrieval现有测试。真实REST、允许集多批和原文尾部案例需要新增或扩展，旧测试通过不自动覆盖。

使用合成千表级目录记录小/大允许集、冷/热查询的实际耗时、候选覆盖、回源查询次数与超界状态，只证明测试环境和数据规模，不承诺百分比收益。不新增遥测系统或费用仪表盘。Embedding用现有Qwen配置与输入上限；真实模型/服务调用按实际授权，替身测试只能证明协议。
