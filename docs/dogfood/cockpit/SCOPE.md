# 能力与证据边界

100项覆盖当前产品公开流程：语义检索/全文续读、SQL草稿/编译/明确执行、状态查询/取消、结果分页与下载、多目标/多轮澄清、来源答案、多来源报告、方法草稿与人工确认、显式Skill采用、个人记忆与修订/忘记、跨用户隔离、公开副本、语义负责人/建议/预填、模型配置和切换、版本失效及恢复。

业务分析覆盖唤醒、VAD、ASR候选选择与标签、NLU及槽位、车端多轮对话、技能路由、幂等动作与回执、TTS/播放/打断、反馈、端云重试以及版本和网络分层。用例明确允许拒绝、取消、合法跳阶段、无标签、缺测和未知，不能要求全链路每个对象都存在。

| 证据 | 能证明什么 | 不能据此宣称 |
| --- | --- | --- |
| 资料校验/52条参考SQL | 冻结合成数据自洽、独立参考在平台可运行 | 模型会找到正确资料或写对SQL |
| 受控模型/协议替身 | 工具契约、状态与UI指定路径 | 真实模型准确率、稳定性 |
| 当前真实模型试用 | 该模型/配置/版本上实际执行的案例 | 其他模型、所有问法、生产质量 |
| 合成平台 | SQLite与受控错误/取消/分页/权限行为 | 真实车端、真实数据平台接入 |
| 无音频日志 | 结构化链路和人工标签的分析能力 | 真正声学识别、听感、真实声学鲁棒性 |

没有车端原始音频、词级对齐或完整音频标签，因此不要求WER/CER、声学识别评测。没有合成chunk数量，不用TTS attempts或播放段数替代chunk吞吐。网络末次观测和阶段区间只能支持关联/覆盖，不能自动证明因果或完整依赖关键路径。日mart只支持UTC整日及其现有维度，不能从按日统计精确恢复小时或语言切片。

模板100项全部not_run；包含全部表与文档不等于覆盖所有字段组合、并发调度或未来新增能力。原零售试用和旧修复验证仍是各自版本的历史证据，不能算本包已经通过。
