# 语音分析核对清单

此文件只含公开合成定义；可作为本轮方法附件，不含参考数值。

- 问题对象：轮次、session、attempt、候选、槽位、operation、回执、播报片段。
- 日期：原始业务时间、收到时间、UTC自然日、快照排他终点。
- 用户交互：有效完整会话、有效轮次、授权与非实验车辆。
- 唤醒：按自身观测筛选，拒绝及未建session也需保留。
- 按键与连续入口：允许没有唤醒记录，不视为埋点故障。
- VAD：语音片段与背景/静音片段分开，时长不替代轮次数。
- ASR：attempt_no是尝试次序，selected_for_nlu决定实际采用候选。
- ASR标签：只有reference_text非空子集，缺预测仍留在分母。
- NLU：解析成功和意图正确分别度量，selected_for_dialogue确定采用。
- 槽位：必要性、是否解决、来源轮次和当前轮次分别保留。
- 车端对话：同session允许多轮；与Data Agent会话/任务不可混用。
- 技能：路由选择不表示动作成功；回退与再试不新增逻辑动作。
- 动作：operation_key定义逻辑动作，invocation_id是传输尝试。
- 回执：confirmed不被晚来的unknown降级，未知先查证。
- TTS：生成成功不等于播放完整，多片段允许流式。
- 首音：输入结束到首个实际可听片段，不把输入时长再算一次。
- 时延：缺测为NULL，单调偏移可比较，秒精度墙钟不复原毫秒。
- 重叠：阶段耗时不能直接相加成关键路径。
- 反馈：无反馈不等于满意；反馈覆盖率和有反馈正评率分别给分母。
- 版本：使用session或attempt冻结版本，不用车辆current_build替代历史。
- 网络：末次观测分组是关联分析，不是网络造成失败的因果证据。
- P95：最近秩，不能平均分组P95。
- 比率：总体用计数加权，空分母NULL。
- 贡献：变化值可为负，合计变化为零时占比不定义。
- 来源：报告与方法保留所有采用结果的原条件和版本。
- 执行：展示SQL与保存报告均不会增加查询授权。
