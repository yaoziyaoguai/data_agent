# {{run_prefix}}语音阶段比较方法

独立公开模板，仅含合成业务定义，不含私人聊天、结果、记忆或独立答案。

1. 先确认目标是ASR服务成功、标签转写准确、NLU意图匹配、任务达成还是播报体验，不能把这些量互换。
2. 固定UTC半开区间、快照、有效轮次、语言和端侧/云侧范围。ASR最终尝试率以每轮最后可见尝试为分母；任务达成率另用eligible轮次。
3. 首播时延从input结束算到首个played_ms>0片段的start_offset，无首音为NULL。P95采用最近秩，不能平均分组P95。
4. 查询先展示，只有用户明确执行后才运行。比较中分别保存每个结果的条件和版本。
5. 结论区分观察差异与原因假设，依赖版本/语言/入口组成不一致时先分层。

需要时读取附件method-checklist.md。所有依赖以当前有效版本为准；停用后不得继续采用。
