# Dogfood 接续点

- run_id / run_prefix / 包版本 / 代码commit：
- 本轮用户授权、模型/费用模式与运维范围：
- 当前URL、服务/数据库/runtime/profile的无秘密引用：
- 角色/归属/检索/记忆/源指纹实际情况：
- results.json路径、各状态计数（合计160）：
- 当前case_id/attempt_id及最后完成步骤：
- 关键task/run/query/result/report/asset/operation与版本：
- 在途、unknown、取消待查证及不能重做的操作：
- 已确认问题及证据：
- 未覆盖项和具体blocked原因：
- 本轮创建/修改对象及恢复/清理情况：
- 下一条应做的精确动作：
- 不要重复的已完成步骤、不要覆盖的其他Agent记录：

不要写凭据值，不把旧unknown当失败后重新执行，不因换Agent或恢复而给原请求补额。
